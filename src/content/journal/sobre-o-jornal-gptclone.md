# Sobre o Jornal GPTCLONE

O Jornal GPTCLONE é a secção de registo técnico do projeto. Aqui publicamos:

- Notícias do projeto
- Atualizações de desenvolvimento
- Marcos atingidos
- Anúncios de lançamento
- Decisões técnicas
- Alterações de arquitetura
- Relatórios de desenvolvimento
- Notas de investigação
- Sumários de progresso

## Formato dos artigos

Cada artigo do jornal inclui:

- Data de publicação
- Data de atualização (quando aplicável)
- Autor
- Categorias e tags
- Tempo de leitura estimado
- Artigos relacionados
- Índice de conteúdos (gerado automaticamente)
- Blocos de código
- Imagens
- Referências e citações

## Princípios editoriais

- **Precisão técnica**: Todas as explicações técnicas distinguem factos estabelecidos de planos e ideias experimentais.
- **Transparência**: Não afirmamos funcionalidades como implementadas quando estão apenas planeadas.
- **Acessibilidade**: Todo o conteúdo é público e gratuito, sem necessidade de registo.

## Como contribuir

O conteúdo do jornal é mantido no repositório público do blog. Consulte a documentação de contribuição para mais detalhes.
