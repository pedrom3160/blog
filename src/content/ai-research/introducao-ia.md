# Inteligência Artificial: Uma Introdução

## O que é a IA?

A Inteligência Artificial (IA) é o ramo da ciência da computação dedicado a criar sistemas capazes de executar tarefas que, tradicionalmente, requerem inteligência humana. Estas tarefas incluem raciocínio, aprendizagem, percepção, compreensão de linguagem natural, tomada de decisão e resolução de problemas.

## Ramos principais da IA

A IA pode ser dividida em várias áreas inter-relacionadas:

| Ramo | Descrição | Exemplos |
|------|-----------|----------|
| **Machine Learning (ML)** | Algoritmos que aprendem padrões a partir de dados, sem programação explícita para cada tarefa. | Regressão, árvores de decisão, redes neurais |
| **Deep Learning (DL)** | Subconjunto do ML baseado em redes neurais artificiais com múltiplas camadas ocultas. | Reconhecimento de imagem, processamento de linguagem natural |
| **Redes Neurais** | Modelos computacionais inspirados no funcionamento de neurónios biológicos. | Perceptrónio multicamada, CNN, RNN |
| **Processamento de Linguagem Natural (PLN)** | Interação entre computadores e linguagem humana. | Tradução automática, análise de sentimento, chatbots |
| **Visão Computadorizada** | Interpretação e compreensão de informação visual. | Classificação de imagem, deteção de objetos |
| **IA Simbólica** | Raciocínio baseado em regras e representação explícita do conhecimento. | Sistemas especialistas, programação lógica |

## Aprendizagem supervisionada vs não supervisionada

### Aprendizagem supervisionada

O modelo aprende a partir de dados rotulados (pares de entrada e saída conhecida). O objetivo é aprender uma função que mapeie entradas para saídas.

Exemplos: classificação de e-mails como spam ou não-spam, previsão de preços de imóveis.

### Aprendizagem não supervisionada

O modelo aprende a partir de dados não rotulados, descobrindo padrões e estrutura ocultas.

Exemplos: agrupamento de clientes, redução de dimensionalidade, deteção de anomalias.

## Deep Learning e redes neurais

O Deep Learning utiliza redes neurais artificiais com muitas camadas (daí "deep"). Cada camada aprende representações cada vez mais abstratas dos dados.

Uma rede neural típica é composta por:

- **Camada de entrada**: Recebe os dados brutos.
- **Camadas ocultas**: Transformam os dados através de operações lineares e funções de ativação não lineares.
- **Camada de saída**: Produz a previsão final.

Funções de ativação comuns: ReLU, Sigmoid, Tanh, Softmax.

## Estado atual da pesquisa

O campo da IA avança rapidamente. Grandes Modelos de Linguagem (LLMs), arquiteturas Transformers, e técnicas como RAG (Retrieval-Augmented Generation) estão a redefinir o que é possível.

É importante distinguir **factos estabelecidos** (ex: redes neurais podem aprender padrões complexos a partir de dados) de **ideias experimentais** (ex: novos arquiteturas ainda em validação).
